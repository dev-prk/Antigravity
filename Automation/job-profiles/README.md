## Two accounts per portal
All four portals allow only **one account per email + mobile number**. So you need either:
- a **second email and phone number** for the second set of accounts, or
- **one account per portal** that uses Profile B (DBA), with the Lead keywords added to it. Naukri lets you keep up to 4 resumes and choose which one to send when you apply.

## Facts used
Every number comes from the 30-Oct Db2/Postgres resumes. Some claims in older resumes don't match those, so I left them out: 180+ instances, 30+ MySQL on AWS/GCP, a Softility start date of Jan 2025, and a 30% storage saving instead of ~60%. A recruiter who compares versions will notice the differences, so delete or fix the old resumes.

# Scope: E2E Testing Track

## Architecture
- `TEST_INFRA.md`: Methodology and coverage inventory.
- `tests/e2e/test_medium_hard_codekata.py`: 4-tier opaque-box test suite for Medium & Hard headless CodeKata automation.
- `TEST_READY.md`: Signal that test suite is complete with execution instructions.

## Coverage Requirements
- Tier 1: Feature coverage (R1, R2, R3, R4)
- Tier 2: Boundary and corner cases
- Tier 3: Pairwise cross-feature interactions
- Tier 4: End-to-end workload scenarios

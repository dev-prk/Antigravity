# AI-OS Reused Cognitive Skills

This directory provides zero-duplication access to global Antigravity reasoning skills via relative symbolic links.

## Linked Skills
1. **claude (`claude/`)**:
   - 4-phase cognitive scratchpad reasoning protocol (Understand -> Classify -> Execute -> Verify).
2. **orchestration (`orchestration/`)**:
   - Task decomposition, bounded subagent delegation, and effort budgeting.
3. **loop-engineering (`loop-engineering/`)**:
   - Closed-loop execution pattern with dual exit gates, circuit breakers, and budget caps.
4. **chain-of-mindset (`chain-of-mindset/`)**:
   - Dynamic cognitive mode switching across Algorithmic, Spatial, Divergent, and Convergent modes.

All symlinks point to `../../../.agents/skills/<skill-name>` to preserve workspace portability across clones.
